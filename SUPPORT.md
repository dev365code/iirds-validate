# Support

The software is free and stays free, and there is no paid tier of the judgement
itself: a free run and a supported run give the same result on the same file.

Professional support is available for the work around it — update guarantees
when the specification changes, backports to a version you have frozen, help
with embedding and integration, and change-impact notes for your product.
Terms for using the project's name and marks will be published separately.

- Bugs and false positives: [open an issue](https://github.com/dev365code/iirds-validate/issues)
- Security reports: see [SECURITY.md](SECURITY.md)
